## Release flow (every drop)

1. ☐ Edit → `bash -n` → commit (Confidence/Scope-risk/Tested trailers)
2. ☐ `sudo ./build_pi5_image.sh --fast-compress` (gate must PASS)
3. ☐ `sudo bash /home/pi/tmp/audit-v1xx.sh output/*.img.zst` (ALL PASS)
4. ☐ `chmod 644 output/*`, regenerate zst-only SHA256SUMS
5. ☐ scp image + SHA256SUMS → Desktop, Get-FileHash verify
6. ☐ **User reflashes + tests → then and only then:** push, imager JSON rehash,
   split parts + join-verify, GitHub release, update README/CHANGELOG badges
7. ☐ Handover §next + notepad entry + vault copy
