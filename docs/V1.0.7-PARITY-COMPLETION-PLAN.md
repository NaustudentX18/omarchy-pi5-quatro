## Executive Summary

The upstream Omarchy project published the **4.0.3 Security Update** on September 8, 2026. This release delivers major AI agentware expansions, critical system security hardenings, and multiple desktop stability fixes.

Because existing Omarchy Quattro Pi 5 systems run live without needing a destructive reflash, **Omarchy Quattro v1.0.7** delivers an in-place upgrade script (`updates/v1.0.7-update.sh`) that brings any running v1.0.5 or v1.0.6 Pi 5 box to 100% like-for-like Omarchy v4.0.3 parity in seconds.

### 2. Security Hardenings

| Security Fix | Impact & Parity on Pi 5 |
|---|---|
| **Mise Wrapper Hardening** | Upstream hardened command-wrapper input parsing against shell injection. Synchronized via `/opt/omarchy/bin` and `/usr/bin`. |
| **Plugin Authentication Boundary** | Restricted third-party plugin access to internal authentication tokens and keyring secrets. |
| **Sudo Expiry Enforcement** | Enforces timeout and cleanup for temporary passwordless sudo escalations. |
| **Privileged Sleep Hooks** | Migration `1788662350.sh` inspects and repairs `/usr/lib/systemd/system-sleep/` entries to ensure strict `root:root` ownership and `0755` permissions, moving untrusted overrides to root quarantine. |
| **Kitty Remote Control** | Migration `1788745941.sh` disables unrestricted `allow_remote_control yes` in Kitty configuration, isolating terminal sockets. |
| **Lock-Screen Path Pinning** | Pinning explicit binary paths for screen-locking authentication to prevent PATH hijacking. |

### 3. System Refinements & Community Issue Mitigation

| Upstream / Community Issue | Resolution in v1.0.7 Update |
|---|---|
| **Mise Auto-Prune Regression** | Migration `1787215483.sh` sets `mise settings set upgrade.auto_prune false` so tool versions in active use are never removed. |
| **1Password Window Scaling** | Enforces `--force-device-scale-factor=1` in 1Password launcher flags to prevent oversized windows on scaled HiDPI / XR displays. |
| **Legacy Icon Font Collision** | Migration `1788848726.sh` retires obsolete `~/.local/share/fonts/omarchy.ttf` and regenerates font cache (`fc-cache -f`) to ensure new glyphs (Hermes, OpenClaw, Cursor) render cleanly. |
| **Launcher 'No Matches' Bug** (Reddit report) | Refreshes `update-desktop-database` across `/usr/share/applications` and `~/.local/share/applications`, ensures Walker application index and Elephant providers are properly linked and populated. |
| **Panel Freezes on Custom Plugins** (Reddit report) | Protects Quickshell bar configuration from illegal write attempts, maintaining UI responsiveness. |
| **Broadcom Wi-Fi DKMS** | Note: Upstream x86 switched `broadcom-wl` to `broadcom-wl-dkms`. On Raspberry Pi 5, onboard Wi-Fi uses the standard kernel driver `brcmfmac` via `wireless-regdb` and `linux-rpi-16k`, which is unaffected by upstream's x86 DKMS transition. |
| **Panther Lake Kernel (7.2.3)** | Upstream x86 Intel kernel. Pi 5 continues using the native `linux-rpi-16k` 16KB-page kernel with Broadcom VideoCore VII KMS acceleration. |

## 🛠️ Update Execution Architecture (`v1.0.7-update.sh`)

The in-place update performs the following operations idempotently:

1. **Verify Root Privileges & Architecture**: Confirms execution on Arch Linux ARM `aarch64`.
2. **Synchronize `/opt/omarchy`**: Pulls tag `v4.0.3` (or branch `quattro`) directly from `omacom/omarchy.git`.
3. **Deploy Core Binaries**: Updates `/usr/bin/omarchy*` and `/usr/share/omarchy/bin/*` to v4.0.3, eliminating legacy symlink shadowing.
4. **Update System & Parity Packages**: Runs `pacman -Syu` and verifies `openclaw`, `cursor-cli`, `openai-codex-desktop`, `perplexity`, `visual-studio-code-bin`, `usage`, `imv`, `hyprland-preview-share-picker`, and `flatpak`.
5. **Execute Upstream Migrations**: Runs migrations `1785090473.sh` through `1788848726.sh` (Hermes CLI, Muse Code, Kitty hardening, font retirement, sleep hooks).
6. **Apply Pi 5 Specific Optimizations**:
   - Re-verifies Headless monitor fallback watchdog in `/usr/bin/omarchy-hyprland-monitor-watch`.
   - Re-verifies Tailscale remote Ollama host (`100.127.91.97:11434`).
   - Re-verifies Walker terminal runner (`alacritty -e`) and unhides `btop`.
   - Re-verifies Super+D application launcher binding.
7. **Refresh Caches & Reload Compositor**: Runs `fc-cache -f`, `update-desktop-database`, and reloads Hyprland/Walker without terminating active user sessions.
